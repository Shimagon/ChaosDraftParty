## 試行錯誤記録 (徹底)

### Squash 反復 (6 回)
1. 着地 Y 0.65 → User「もっとやわらか」 → 0.55
2. やわらか → User「ジャンプに合わせて、空中ブニブニ、スライム感」 → Airborne mode + Sin wobble
3. 戻り 0.5s → User「戻り中ジャンプで急に通常に戻る」 → coroutine の discontinuous 問題
4. **Spring 物理移行** → User「天才、素晴らしい」 ★
5. 頭調整 → User「少し柔らかすぎる」 → dampingRatio 0.35→0.45 / impulse -12→-10
6. (進行中) 手足 squash 連動 / 足めり込み

### Blink 反復 (4 回)
1. localScale.Y=0 で潰す → 目消える
2. EyeClosed mesh swap → 目消える (位置ずれ)
3. localScale.Y で smoothstep → 目が前後方向に薄くなって正面消失 (rotation X -90° 罠)
4. **localScale.Z + position 補正** → User OK ★ (mesh pivot offset の数値解析)

### 失敗パターン (二度踏まない)
- 「scale で消す/伸ばす」は decal/3D 凸 mesh で物理的に変、mesh swap or 物理基底に切替が defacto
- coroutine + SmoothDamp の戻りは position 駆動で discontinuous、Spring 物理に切替
- Unity localScale は Transform origin center で scale、mesh pivot offset があると visible が動く
