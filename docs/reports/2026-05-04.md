## 採用設計

### 頭収納の階層構造（user 提案）
```
mixamorig:Head (bone、何も bind しない、Mecanim が動かしても無害)
  ※ HeadAnchor の親は EGGYBOT_v16 root（Walking 揺れゼロ）

EGGYBOT_v16 (root)
└─ HeadAnchor (empty + SphereCollider 0.30 isTrigger=true、固定 = 当たり判定)
   └─ FaceVisual (empty、crouch で上下動する）
      ├─ HeadMesh (静的 MeshRenderer)
      ├─ Eye_L (静的 MeshRenderer)
      ├─ Eye_R (静的 MeshRenderer)
      └─ Mouth (静的 MeshRenderer)
```

### アニメーション設計
**Enter (stand → crouch)**:
1. 頭ぴょんッ上昇 (+0.10) + 蓋開 (90°) ─ **並列**
2. 頂点で hold (0.05s)
3. 頭スポン落下 (-0.53) + 蓋同時閉じ ─ **並列、ラグなし**
4. 蓋反動 bounce: slam -8° → 戻り +5° → 0° settle

**Exit (crouch → stand)**:
1. 頭が bowl から高跳 (+0.18) + 蓋開 ─ **並列**
2. 頂点 hold
3. 頭が body 上に降下 (0) + 蓋同時閉じ ─ **並列**
4. 蓋反動 bounce

### 視覚改善
- HeadMesh 専用 matte material 新規作成 (`EGGYBOT_Pink_Head_Matte.mat`、smoothness 0.55→0.10、specular OFF)
- bowl は元の光沢 material キープ（capsule との対比で頭が落ち着く）
- crouchDepth = 0.53（顔 visual center が bowl rim Y=0.50 にちょうど着く）

## 試行錯誤記録（教訓）

### 失敗 1: Head bone を直接動かそうとした
- 初期実装は `head.position.y = 0.30` で head bone を移動
- **動かない** → 1 時間以上潰す
- 真因: HeadMesh / Eye / Mouth の SkinnedMR が **Hips bone で skinning**（Head bone 無関係）
- Head bone を動かしても visual に反映しない

### 失敗 2: Awake で head reference 取れない
- `anim.GetBoneTransform(HumanBodyBones.Head)` が Awake で null 返す
- Lazy-fetch in LateUpdate で回避

### 失敗 3: Editor focus 喪失で Lerp 進まない
- Game view が非フォーカスで playerLoop が止まる
- Time.deltaTime が ~0 で Lerp が進行しない
- `Application.runInBackground = true` で回避（ビルド副作用避けるため `#if UNITY_EDITOR` ガード）

### 失敗 4: HeadAnchor を Hips bone child にして Walking で揺れすぎ
- 並列 agent 実測で X 揺れ 82mm（元 Hips skinning の 68mm より悪化）
- root child に再 reparent で完全静止に

### 失敗 5: Hinge の world position 破壊
- 過去のセッション中 reparent 操作で Hinge の local position が (0,0,0) に reset、root world Y=0.20 と相まって Hinge world 位置がバグ
- 強制 `hinge.position = (0, 0.50, 0.336)` で復旧

### 失敗 6: 「下に行きすぎ」と「位置がずれてる」を取り違え
- crouchDepth=0.95 で底突き抜け → user 「下に行きすぎ」
- crouchDepth=0.674 で「ずれすぎ」
- 最終的に `head visual center = bowl rim (Y=0.50)` を target に逆算 → crouchDepth=0.53 で着地

### 失敗 7: 完了報告が早すぎた
- User 「ちゃんとしっかり最後まであなたが確認してから私に報告して」
- 以降は **screenshot 撮って自分で目視確認 → 報告** のフローに修正
