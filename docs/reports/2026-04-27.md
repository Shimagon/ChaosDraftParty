## 採用判断と根本原因
- v15.17 までの skinned mesh 経路では HAND_STRETCH=(1.5, 1.0, 0.9) が **mesh 形状そのもの** に焼き込まれており、SkinnedMesh の bind-pose 補間でわずかな shape distortion が発生
- ユーザーの「引き伸ばされてる」体感の主因は **形状 + skinning 補間の合算**
- → **rigid hand parent** が原理的に正解（skinning math 経由しない）

## 並列実行 3 トラック

### T1: Rigid hand parent (commit 3618995, f0e7b07) ★採用
- Hand_L/R skinned mesh を **SetActive(false)** で hide
- **Hand_L_Rigid / Hand_R_Rigid** = Unity primitive Sphere (localScale 0.22, pure 球)
- LeftUpperArm / RightUpperArm bone に rigid parent
- localPosition は T-pose 時の skinned mesh `bounds.center` に正確に一致
- EGGYBOT_Pink_Arm.mat (ArmClip shader) を sharedMaterial で適用 → SDF clip 自動継続
- **NoArmsMask により UpperArm bone は walking 中も完全静止 → rigid hand も完全追従**
- **skinning bind-pose vs current-pose 補間 artifact が原理的に発生しない**

検証:
- Sandbox_RigidHand.unity で T-pose / Walking play mode 両方で確認
- Walking 中 30 frame サンプリング → hand world position 完全一定
- Multi-angle orbit screenshot 18 枚で全角度確認、引き伸ばし感ゼロ
- 最後に main Sandbox.unity にも適用

### T2: BodyCenterEmpty (commit 9f29350)
- EggybotShaderBinder に **optional Transform `bodyCenterTransform`** field 追加
- 設定された場合、ComputeBodyCenter() で Hips offset 計算をスキップして直接 transform.position を返す
- Hips 配下に `BodyCenterEmpty` GameObject 作成 (world (0, 0.5, 0)) → binder にアサイン
- 効果: SDF center の位置が **Inspector で視覚的に調整可能** に
- 優先順位: bodyCenterTransform > Hips bone offset > bodyRenderer > self.transform

### T3: HAND_STRETCH 緩和 (commit 5dd14f8) — 保険
- `tools/blender/build_eggybot.py` の HAND_STRETCH を **(1.5, 1.0, 0.9) → (1.2, 1.0, 0.95)** に緩和
- 既存 STALE コメント「(1.5, 0.7, 0.95)」を実値に修正
- vertex group binding 用 ellipsoid 半径 (HAND_RX/Y/Z) も同期
- **Blender rebuild 未実施**（Blender 起動してなかった + T1 が成功したので skinning 経路は不要）
- T1 が万が一破綻したときの fallback として保険commit

## 知見・残課題

### 知見
- **SkinnedMeshRenderer の落とし穴**: 100% bone weight でも bind-pose 補間で微小 distortion が出る
- **rigid Transform parent の優位性**: bone が静止している (NoArmsMask) なら Transform parent は完璧、Mixamo bone axis convention を完全無視できる
- **primitive Sphere の有効活用**: Blender FBX の `apply_scale` 系の罠を全部スキップ、Unity 内で完結

### 残課題
- [ ] Hand 4 個 (Hand_L, Hand_R, LeftHand bone tip, RightHand bone tip) のうち 2 個が disable 状態で残っている → prefab 化時に整理推奨
- [ ] Sandbox_RigidHand.unity / Sandbox_StretchTune.unity の test scene 2 つ → user review 後、不要なら削除可
- [ ] HAND_STRETCH (1.2, 1.0, 0.95) は build script だけ更新済、Blender rebuild してない → 必要時に手動 rebuild
