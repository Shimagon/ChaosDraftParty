## 1. Foot 球めり込み問題 — 4 周目で動的解到達

### 経緯 (3 周失敗 → 1 周成功)

| 試行 | アプローチ | User 結果 |
|---|---|---|
| Plan A | CC.center.y 0.55→0.60 + BodyDip | ❌ めり込み (画像 #12) |
| Plan B' | FootSocket localPos.y=+0.14 (bone child) | ❌ 足が消えた (body 内部、画像 #13) |
| v2 | FootSocket localPos.y=-0.04 | ❌ めり込み (画像 #14) |
| **v3e** | **LateUpdate world.y clamp** | ✅ **「結構いいね」** |

### 真因 (Claude 直接実測 + 3 agent 並列調査)

`bone (mixamorig:LeftFoot) world.y` が Animator + PoseLock で動的振動:
- Plan A 実測: 0.011
- v2 計画時: 0.162
- v3 直前: 0.061
- → 同 Play モードで 15cm 振動、固定 offset は構造的に無理

PoseLock は固定 -0.219 で犯人じゃない、**Animator clip Hips Y curve + bone chain dynamic 加算** が真犯人。

### v3e の解

```csharp
[DefaultExecutionOrder(130)] // FootSquash(120) 後
sealed class EggybotFootGroundClamp : MonoBehaviour {
  void LateUpdate() {
    foreach (var foot in _feet) {
      float bottom = foot.position.y - _footRadius;
      if (bottom < _groundY) {
        foot.position += Vector3.up * (_groundY - bottom);
      }
    }
  }
}
```

- 毎フレ Foot 球底を実測 → 床より下なら持ち上げ
- 浮きは Spring wobble そのまま保持 (Mario Odyssey 風自然挙動)
- bone は触らない → PoseLock / Mixamo / Spring 全部非破壊
- M3 で Physics.Raycast に拡張予定 (傾斜地対応)

### 学び

「ある瞬間の bone.y で計算した固定 offset」は Animator 駆動下では脆い。
動的解 (LateUpdate world position clamp) が defacto。Fall Guys / Mario Odyssey も同パターン。

## 2. 動いてる時の口表情

User 要求: 「動いてる時 (walk/run) の口表情、口だけ変わる感じ」。

### 実装

`EggybotFaceAnimator.SetMouthByMovement(planarSpeed, isDashing)`:
- 停止 (speed ≤ 0.4) → Mouth_Smile
- 歩行 (speed ≥ 0.8) → Mouth_Open
- ダッシュ (isDashing) → Mouth_Happy
- 排他: fall / Hit/Happy/KO / jumpMouth 中は no-op
- hysteresis + minHold で chattering 防止

### ジャンプ専用口 (3 commit 目で追加)

`PlayJumpMouth()` Coroutine:
- Mouth_Open + localScale 1.3x で 0.30s 限定
- 踏切 blink と同期
- 「びっくり大きく」感、歩行 Open と差別化
- fallExpressionActive で早期 break

### User 要求の解消

「歩きとダッシュが同じ表情」「ジャンプは少し違う口」を 4 mesh + scale tween で実現。
M3 で専用 Mouth_Jump mesh 追加検討。
