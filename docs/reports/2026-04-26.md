## 達成したこと

### 1. Mixamo Walking + Dance retarget 動作
- Y Bot.fbx / Y Bot@Walking.fbx / Y Bot@TwistDance.fbx を `Assets/ThirdParty/Mixamo/` 配下に配置
- Walking clip: loop ON、その場歩き（`lockRootPositionXZ`）
- TwistDance clip: Avatar = Y BotAvatar で humanoid retarget
- `Assets/_Project/Animations/EggybotAC.controller` で Default Walking 切替可能
- `EggybotNoArmsMask.mask` で腕アニメ OFF

### 2. Sandbox scene セットアップ
- `Assets/_Project/Scenes/Sandbox.unity` に EGGYBOT 配置
- Animator + Avatar アサイン、`ApplyRootMotion=false`
- Camera を -Z（face 正面）に向け、character 180° 回転で Unity 標準 forward に揃え

### 3. **革命的 SDF クリッピング**実装（最重要成果）
URP Stencil shader が信頼できない → **球距離による discard** に置換：
- `EggybotShaderBinder.cs`（C# MonoBehaviour）が body の world 位置 / 半径 / 上端 Y を毎フレーム Hand material に配信（MaterialPropertyBlock）
- `EGGYBOT_ArmClip.shader` fragment shader で「pixel が体球内なら discard」判定
- 描画順・カメラ角度に依存しない確実な動作
- Empty / Collider 不要、純粋シェーダー数学

### 4. 腕 muscle ロック実装
- Shoulder / UpperArm / LowerArm / Hand 全部 `min=max=(0,0,0)` で完全固定
- 理由: EGGYBOT は関節無いキャラ（指も肘もない）
- Mixamo の派手な腕振りに引きずられない

### 5. ボーン位置永久保存システム
- `tools/blender/extract_bone_layout.py`: .blend → `eggybot_bone_layout.json`
- `build_eggybot.py` 起動時に JSON 読み込んで bone 配置
- ユーザー手動調整値が再ビルドしても保持される

### 6. 手の幾何学的最適化
複数の hand_x 値を iteration:
- 0.43（v15.13/v15.15 初期）→ 浮いてる感
- 0.326（体表面）→ 半 in/half out、Stencil で内側 hide
- **0.380（最終 B 案）**: 体内 7cm 隠れ + 体外 17cm 見える → 「肩から伸びた腕」感

## 学習・洞察

### **動画解析が突破口**
静止画では気づかない「頭の脇に手が出る」現象 → 4fps frame 抽出で**全フレーム見渡し** → 即原因特定。
**今後も動画録画 → ffmpeg 抽出**を採用。

### **URP Stencil の罠**
`Stencil { Ref X; Comp NotEqual; ... }` は forward renderer で完全 honor されない。
**SDF クリッピング（geometric volume test）の方が確実**。

### **Avatar T-pose vs FBX rest pose**
Humanoid Rig は muscle space で骨位置を再計算するから、FBX 上の rest pose とは別物。
muscle locked でもアニメ中は Avatar T-pose に動く。
→ Configure → Enforce T-Pose で対処（M2 で着手）。

### **キャラ設計上の trade-off**
| 観点 | UNION 一体化 | 分離 + SDF |
|---|---|---|
| 浮き感 | なし | わずかにある（B 案で改善）|
| アニメで body 歪み | あり | なし |
| 内部 artifact | hollow bowl 内見える | 同じ（足 UNION は別問題）|
| 拡張性（カプセル開閉等）| 困難 | 容易 |

→ **分離 + SDF 採用**（M3 のカプセル開閉アニメに繋がる）
