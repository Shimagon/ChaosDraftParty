## ❌ 失敗したもの (今日 2 回撤退)

### 失敗 1: Sobel 自前 outline (StylizedOutline.shader)
**真因**: threshold tuning が AI 単独で収束不可。
- alpha 1.0 / threshold 1.5: 薄い線
- alpha 0.5: もっと薄い (User 「弱い」)
- threshold 下げる: 全画面塗りつぶし (User 画像 #128)

最終的に `_OutlineColor.a = 0.5` (controled) → 「弱い」批判 → alpha 1.0 + threshold 0.01 → **真っ黒画面**。8-tap Sobel + depth/normal Sobel + UNITY_SETUP_STEREO_EYE_INDEX_POST_VERTEX + _CameraDepthTexture_TexelSize + SampleSceneNormals 2 引数版に修正 (URP 17 対応) しても threshold tuning は外れる。

**学び**: Sobel post-process は threshold が環境依存性極大、AI 単独実装に不向き。Hat in Time / TUNIC 系作品向け、Splatoon / 本作 cartoon パーティには適合しない。

### 失敗 2: CristianQiu OSS (com.cqf.outline)
**真因**: Unity 6.4 で **Render Graph Compatibility Mode が削除された** (Project Settings > Graphics > Render Graph に Compatibility Mode チェック無し)。OSS は `AddRenderPasses` のみ override してて、`RecordRenderGraph` (Render Graph native) 未実装 → Unity 6.4 で **pass が呼ばれない** → 描画されない。

詳細:
- Manifest.json に git URL 追加 → Library/PackageCache に展開 OK
- Asmdef なしで package script がコンパイルされず → Assets/_Project/ThirdParty/cqf-outline/ にコピー (OSS 内に Cqf.Outline.asmdef あった)
- 重複 asmdef conflict → 自作 asmdef 削除
- OSS 型 load 成功、RendererFeature/Volume 配線完了
- IsActive=True、Shader.Find("Hidden/Outline") supported=True
- でも **画面に何も出ない**
- 真因: Render Graph default ON (Compatibility Mode 削除)、AddRenderPasses が呼ばれない

**学び**: Unity 6.4 で動く OSS は **Render Graph native (RecordRenderGraph) 実装必須**。CristianQiu OSS は Unity 6000.3 想定で書かれてて、6000.4 で動かない (README には 6000.3+ 必須と書いてあったが、実際は 6000.3 限定)。
