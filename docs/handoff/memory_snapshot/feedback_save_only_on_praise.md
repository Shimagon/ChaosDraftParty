ChaosDraftParty セッションの学び保存ルール。

**ルール:** skill（`.claude/skills/chaosdraftparty-gotchas/SKILL.md`）と memory への「これは罠だった」「この手順は有効」系追記は、**ユーザーが明示的に褒めた / 承認した時のみ** 行う。correction 後に Claude が自発的に保存しない。

**Why:**
- 途中経過の誤学習リスク。ユーザーは候補案に「やっぱ違う」と後で翻すことが多い。未確定の判断を memory 化すると将来セッションが誤前提で動く
- 褒め（「ナイス」「戻った」「いい感じ」「OK」）はユーザーが **最終確定を意思表示した** シグナル
- 毎 correction 後に書くと memory がノイズで膨れ、本当に重要なルールが埋もれる

**How to apply:**
1. 修正 / 実装完了を報告
2. ユーザーの次レスを読む：
   - **正フィードバック（「ナイス」「戻った」「良い」「OK」等）** → skill / memory 追記の合図
   - **「まだ変」「違う」等 negative** → 保存しない、追加修正続行
   - **無言で次タスク指示** → 保存しない（承認未確定）
3. 正フィードバック + 「記録して」と明示 → 即追記 + commit
4. 正フィードバックのみで記録指示なしの時、重要罠なら「skill に残していい？」と 1 度だけ確認
5. 罠以外（単なる色・位置調整など）は褒められても記録不要

**初回ユーザー発言（2026-04-24）:** 「同じミスしないようにスキルズに記録してね。ナレッジに残して同じミスしないように。この流れもルールにしてね。うんでも、俺が褒めた時だけね。」
